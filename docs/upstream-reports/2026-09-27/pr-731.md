## Summary

**Decline.** This is LLM-provider plumbing: a GitHub Models endpoint behind the OpenAI-compatible client. Berkshire is Claude-only by decision, so the provider has nothing to plug into, and the PR carries no idea beyond the provider.

## What it does

It adds a `github_copilot` provider. `GitHubCopilotClient` subclasses `OpenAIClient`, points it at `https://models.github.ai/inference`, authenticates with `GITHUB_TOKEN`, and adds an `X-GitHub-Api-Version: 2026-03-10` header (`tradingagents/llm_clients/github_copilot_client.py:11`, `:51`). If no token is set, `get_llm()` raises a clear error instead of the OpenAI SDK's misleading `OPENAI_API_KEY` complaint (`github_copilot_client.py:57-66`). The remaining changes are small edits that register the provider: the factory branch, the base URL and env-var tables, a model catalogue entry, a CLI menu row, the README, and `.env.example`. It also adds `default_headers` to `_PASSTHROUGH_KWARGS` (`tradingagents/llm_clients/openai_client.py:149`), so every OpenAI-compatible provider now passes through caller-supplied headers. The problem it solves is letting users with a GitHub Copilot or Models entitlement run TradingAgents without a separate paid API key.

## Soundness

- **The catalogue model IDs look wrong for the endpoint.** GitHub Models IDs carry a publisher prefix (`openai/gpt-4.1`), and the PR's own tests use `openai/gpt-4o`. The catalogue lists bare `gpt-4.1`, `gpt-4o` and `o3-mini` (`tradingagents/llm_clients/model_catalog.py:75-88`). A model picked from the CLI menu is therefore likely to be rejected by the endpoint. The reverse also holds: the prefixed ID that works emits the "unknown model" `RuntimeWarning`, since `validate_model` checks against the bare IDs. The tests do not catch this because they mock `NormalizedChatOpenAI` and never make a real call.
- **Misleading name.** The endpoint is GitHub Models, not the Copilot chat API. `models:read` PAT tokens have GitHub Models rate limits, which are low for a multi-agent run (roughly 12 or more LLM calls per ticker), so free-tier users would hit 429s partway through a run.
- **The API version is hard-coded.** It is a date string, but callers can override it through `default_headers`. That is acceptable.
- Point-in-time and look-ahead safety are not affected, since the change does not touch data or decisions.
